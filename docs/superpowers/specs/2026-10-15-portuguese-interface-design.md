# Interface em português do Brasil

Escopo aprovado pelo usuário: traduzir a interface completa, relatórios PDF/CSV, mensagens de erro, confirmações e instruções exibidas. Glossário: Overview = Visão geral; Environments = Ambientes; Machines = Máquinas; Work requests = Solicitações; Assessment = Coleta (o produto continua Java Assessment). Nomes fornecidos pelo usuário, marcas, caminhos, comandos, propriedades, estados de protocolo e identificadores de API permanecem intactos.

Traduzir textos na origem, sem tradução automática de dados arbitrários nem substituição global do DOM. Usar pt-BR na apresentação de números/datas. Mensagens operacionais históricas conhecidas serão traduzidas apenas na apresentação, preservando o registro original. CSV para pessoas terá cabeçalhos legíveis; os identificadores internos do inventário/API não mudam. Preservar precisão de versões, números técnicos e timestamps do contrato de dados.

Validar navegação, fluxos administrativos, acesso, download ZIP/terminal, relatórios e solicitações em navegador local. Verificar PDF e CSV, caracteres acentuados, opções com valores internos estáveis, e empacotamento final. Publicação e Git não estão solicitados.
