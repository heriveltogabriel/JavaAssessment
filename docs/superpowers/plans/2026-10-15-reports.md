# Inventory Reports Implementation Plan

> **For agentic workers:** Use executing-plans to implement this approved plan task by task. User explicitly authorized implementation without additional review pauses.

**Goal:** Deliver selectable inventory reports with JDBC details, filters, CSV and PDF in a new local release.

**Architecture:** Reports.java owns allowed columns, parameterized queries, distinct host counts, revision and CSV. ReportPdf.java renders the same report result. reports.js owns filters, column selection, pagination and downloads; app.js supplies session/navigation integration. Existing snapshot and export semaphore protect consistent reads and bounded work.

**Tech Stack:** Java 17 dashboard, SQLite JDBC, vanilla JavaScript/CSS, local browser regression fixtures. No agent discovery change.

---

- [x] Query/API: create server/Reports.java and tests/ReportsTest.java. Model keys machines/java/servers/jdbc/environments. Fields environmentId, machine, os, architecture, javaVersion, serverType, serverVersion, datasource, driver, driverVersion; text contains literal, versions equality. Bind values, correlate related field filters. Return columns/availableColumns, rows, summary, filters, revision, generatedAt, pagination. Check host count with two matching servers and reject cross-record product/version pairs. Run javac and ReportsTest with existing SQLite libraries.
- [x] Export: create server/ReportPdf.java and focused tests. `ReportPdf.write(OutputStream, Map<String,Object>)` receives title/generatedAt/filters/columns/rows/summary. `Reports.csv(Writer, Map<String,Object>)` uses exact selected columns and all filtered rows. Test escaping, formulas, accents, empty report, long cells and >1 page. Render and inspect exported PDF.
- [x] HTTP: AssessmentServer.java adds GET /api/reports, /api/reports/options, /api/reports/export.csv, /api/reports/export.pdf for both human roles; same password/session checks. Read snapshot; reuse exportSlot; reject stale revision with 409. No mutating endpoint. HTTP tests include reader, unauthenticated, stale revision, all-pages export.
- [x] UI: create web/reports.js and web/reports.css. Integrate #reports route, side navigation, container, session clearing and refresh in app.js/index.html. Five model cards/select, collapsible filter form, indicators, checkboxes for columns, 20/50/100 page sizes, CSV/PDF downloads. No collection date/coverage controls. Escape all remote labels; prevent stale responses after navigation/session end. Browser tests cover JDBC filter/columns/export and 390px width.
- [x] Release: synchronize validated source into operational build mirror; reserve next bridge/target pair via existing release builder; run required regressions and public candidate verifier including internal ZIP manifests. Build new-install installer, write release notes with compatibility warning and test instructions. Preserve published 2.0.13. Commit locally; do not deploy/push without new request.
